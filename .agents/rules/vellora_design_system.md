# Agent Rules: Velora Villas Design & Layout System

When writing or updating code for Velora Villas:

1. **Brand Identity**: Use "VELORA VILLAS" branding and tagline "Where nature meets quiet luxury".
2. **Color Tokens**:
   - Dark Base: `#201F22`
   - Secondary Dark: `#707070`
   - Silver Tone: `#858585`
   - Full White: `#FFFFFF`
3. **Typography Scale (Inter Font)**:
   - `H1`: 119px (Inter Regular)
   - `H2`: 64px (Inter Regular)
   - `Body 1`: 30px (Inter Regular)
   - `Body 2`: 22px (Inter Semi Bold)
   - `Body 3`: 18px (Inter Regular)
   - `Button`: 16px (Inter Regular)
4. **Grid Layout**: 80px outer padding on left and right on desktop. 5-column grid system (575px, 330px, 318px, 293px, 269px).
5. **Components**: Rounded pill navigation buttons, rounded cards (`rounded-[28px]`), diagonal arrow `↗` badges, and Lenis/Framer Motion animations (`SmoothScroll`, `Parallax`, `MaskReveal`, `TextSplitReveal`, `MagneticButton`).
